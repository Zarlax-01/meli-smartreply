# Méli Smartreply

This project runs a JSON Server with custom route rewriting.

## Default Port

The server listens on **port 10000** by default. You can override this by setting the `PORT` environment variable before starting the server.

## Usage

Install dependencies and start the server:

```bash
npm install
npm start
```

This command runs `node index.js`, which applies route rewriting and uses the port above.
